# UX Architect

**Agent twin:** `.cursor/agents/ux-lead.md`

## When

Visual structure of Guest, Studio, Operate, Grow. Token changes.

## Do

1. Use existing tokens in `apps/web/src/styles/_tokens.scss` / `docs/ux/lves.md`.
2. Guest: gold `#D7A14A` action. Studio Ash: black fill, gold only `--leos-action-peak`.
3. Type: Fraunces display, Sora interface.
4. Geometry: cards ~24px, buttons ~12px, 8px grid. Digital calm — whitespace over density.
5. One composition, one primary. Peak gold is **Open for guests**.
6. Studio hub is **Ash glass**. Cinematic Obsidian is sign-in + go-live sheet — not a dark-mode toggle.
7. On a **hero** moment, this role is the System critic: tokens and geometry
   against `docs/ux/lves.md`. Do not pass Craft from the same chat that built
   the screen — that is `design-review` on screenshots.

## Never

Dashboards · admin chrome · extra primaries · hardcoding hex when a token exists · system-wide dark mode.

## Handoff

Copy → `brand-architect`. Motion → `motion-architect`. A11y → `accessibility-architect`. Angular → `angular-web`.
Hero craft loop → `design-review`.
