## Human Confidence Index (HCI)

One question: **Am I confident?**

### Experience

| Moment | Confidence question | Status |
|--------|---------------------|--------|
| Arrival | Am I in the right place? | ✓ Venue chrome |
| Join | Did I join? Do I know what to do? | ✓ You’re in · place · See the board/menu |
| Browse | Do I know what I can choose? | ✓ Sections · search · + add · **G-04 choices sheet** when required |
| Order | Did they receive it? | ✓ Received banner · concierge timeline |
| Pay | Did I pay? Can I trust this? | ✓ Total · tip · **Mine · Visit · Equal share** · remaining · confirm trust |
| Wait | Are they making it? | ✓ Timeline |
| Receive | Is it ready? | ✓ Ready + timeline |
| Leave / Complete | Am I finished? | ✓ Receipt · Leave · Entry |
| Return | Welcome back? | ✓ One moment after scan · Complete stays calm · short return splash |

### Studio

| Moment | Confidence question | Status |
|--------|---------------------|--------|
| Welcome / Create | Can I start without fear? | ✓ Setup v1 |
| Choose Experience | Do I know what I’m creating? | ✓ Setup v1 |
| Identity → Go Live | Ready to welcome guests? | ✓ Setup v1 **FROZEN** |
| Home | Am I ready? | ✓ Readiness door · **calm floor live counts** |
| Operate | Is everything under control? | ✓ Overview · next action · Needs you/Ready/Preparing · Staff handoff |
| Grow | Do I hear calm truth (not BI)? | ✓ One breath · one suggestion · pack nouns |
| Team | Can I assign Experiences · know who can do what? | ✓ Assignment · grouped actions · device Idle/In use · End now |

**Backlog = moments.** Not Marketplace. Not Neo. Not Setup redesign.
