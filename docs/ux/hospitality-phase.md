## One sentence

Anyone can build software. Few build software that *hosts* people. Hospitality is the differentiator and the benchmark.

## Phase

Was: Experience Refinement · Craft.  
**Now: Hospitality Phase.**

Roadmap is no longer Pages → Features → Settings.

```text
Moments → Feel → Trust
```

Depth over screens. Horizontal evolution — deepen the experience — not vertical accumulation of settings.

---

## Four pillars

Judge every future design decision against these. If a feature increases none of them, it does not belong.

| Pillar | Feeling |
|--------|---------|
| **Confidence** | I know what’s happening. |
| **Calm** | Nothing feels stressful. |
| **Hospitality** | I’m being welcomed. |
| **Continuity** | The software remembers me. |

---

## Three living surfaces

| Surface | Feeling | Not |
|---------|---------|-----|
| **Experience** | I’m in the right place. | An app to figure out |
| **Studio** (Setup · Home) | I’m ready to welcome guests. | Admin / configuration |
| **Operate** | Everything is under control. | A dashboard |
| **Grow** | A trusted manager told me the truth. | Excel / Insights |

*(Grow is a Studio mode — almost invisible — not a fourth product.)*

None of these are software feelings. They are human feelings.
